# Guided recorded instruction-program tutorial

The existing cross-layer inspector now offers **Open recorded program
tutorial**. It lazy-loads the already qualified retained V17 observation
viewer alongside a source excerpt, independent arithmetic exercises and
explicit evidence limits. Closing it unmounts the view and clears local
selection. It is a reference exercise, not a new curriculum lesson.

The original compiler pin `f5e81f985ff3e2771ad0f132d483f5cf74976ad6`,
retained capture bytes, display pins and validators are unchanged.
[The debugger walkthrough](ordered-program-debugger-v1.md) retains their
exact provenance. No compiler command, source mutation, session transport,
new capture, curriculum registration, `FE2O3_PIN` change or maturity
promotion is introduced.

The exercise distinguishes the declared instruction sequence from the
atomic whole-program CPU checkpoints. Arithmetic answers are independent
source expectations, not newly observed output memory. Logical lane-zero
values are not physical VGPR contents. LLVM remains in the compilation
path; native decoding, GPU execution and protected publication are separate.
