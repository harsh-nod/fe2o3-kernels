# The reference effect comes from safe Rust MIR. The GPU output, ranked index,
# typed value, and path condition come independently from the GPU projection.
# A strict one-to-one match is required before this request is constructed.
# A direct safe input[index] read joins only to matching ranked read/view/index,
# scalar, allocation-origin, stride, and guard evidence. Multidimensional or raw
# reads, unresolved load symbols, noncanonical loops, and unsupported expressions
# fail Incomplete.

# Per-effect receipt admission materializes these real PLIRON operations:
#
#   kernel.access (%output, %index) [kind=Write]
#   kernel.ownership_contract (%output)
#     [coverage=ExactEffectDomain, partition=ExactSets]
#   proof.obligation <exact MIR/effect identities> FunctionalRefinement
#   proof.evidence_ref <receipt identity> Proved Mir
#   proof.require_effect_refinement (
#     %output, %index, %point0, %point0,
#     %true, %true, %true, %true, %gpu_value, %reference_value
#   )
#
# Production then performs three mandatory compiler-owned stages in order:
#
#   1. derive/reconcile the exact semantic MIR/live-PLIRON contract
#   2. derive/validate the strict pointwise/permutation/fold/recurrence contract
#   3. generate and run one generic Verus conditional-lemma checker
#
# The production report cryptographically binds the exact instantiation,
# retained effect receipts, and tool execution outside the lemma. Receipts are
# not logical premises in one whole-kernel Verus theorem. Candidate
# declarations and generated identity comments are not premises. The move-only
# result is required before KIR lowering.
