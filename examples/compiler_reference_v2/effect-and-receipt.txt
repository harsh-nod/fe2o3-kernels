# Safe Rust MIR supplies each reference effect. The GPU projection supplies
# its output view, index, typed value, and path condition independently. A
# strict one-to-one match is required before either request is constructed.
# A direct safe input[index] read retains its exact Rust bounds condition, but
# it remains Incomplete until compiler-owned extent facts imply that condition
# over the complete output domain.

# Per-output admission materializes one exact live-PLIRON relation and one
# policy-checked Checked staging record for output0, then does the same
# independently for output1.
# The private request-to-require transition is represented by:
#
#   proof.require_effect_refinement(output0, exact formulas, checked staging0)
#   proof.require_effect_refinement(output1, exact formulas, checked staging1)
#
# These operations bind roles and inputs; they do not prove equality.
# The generated checker does not assume a generic relation lemma. For each
# output it reconstructs and evaluates the compiler-derived formula graphs:
#
#   coordinates: gpu_coordinates(point) == reference_coordinates(point)
#   domain:       gpu_domain(point)      == reference_domain(point)
#   precondition: gpu_precondition(point) == reference_precondition(point)
#   value:        gpu_value(point)       == reference_value(point)
#
# Exact pointwise bit-vector formulas and identical compiler-side IEEE
# operator DAGs are replayable. Caller-selected signature and policy checks do
# not establish proof execution or compiler authority. Checked staging records
# bind the retained MIR and PLIRON inputs but never make either equality true.
#
# PLIRON independently proves and reconciles TotalView, allocation separation,
# output-specific frames and schedules, and ordered-product identity. The
# generated checker does not replay those structural theorems:
#
#   output_product = [output0, output1]
#   separated(output0, output1) =
#     allocation_origin(1) != allocation_origin(2)
#     && noalias_class(1) != noalias_class(2)
#   pliron_structure = total_and_separated(output_product)
#   verus_formulas = exact_formula(output0) && exact_formula(output1)
#   admitted = private_move_only_join(pliron_structure, verus_formulas)
#
# Duplicate views, missing outputs, reordered products, overlapping ownership,
# or substituted formulas stop compilation. ErrorBounded, tensor-component,
# fold, recurrence, permutation, and noncanonical-loop replay roles also stop
# with UnsupportedFormulaReplayRole. That verifier boundary has no invented
# FE2O3-PARALLEL pass code.
